Experiment notes
This prototype is deliberately small. It is not an LLM yet.

Each neuron stores a membrane-like value. Inputs increase that value.

A neuron only communicates when its value crosses the firing threshold.

This allows us to measure how much of the network is actually active.

The eventual research goal is to compare this type of sparse/event-driven computation against dense neural computation.
